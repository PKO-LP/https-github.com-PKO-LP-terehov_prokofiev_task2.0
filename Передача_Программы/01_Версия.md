# Исходные данные программы Угадай число
## Что открыть
Откройте папку с проектом Угадай_число в VS Code (File -> Open Folder...).
## Название и исходная версия
Название: Угадай число (консольная игра на Python). Исходная версия: 0.1.0 (до внесения исправлений).
## Файлы и запуск
Основной файл: app.py (дополнительные медиафайлы и сторонние библиотеки не требуются). Команда запуска в терминале из основной папки: python app.py (на Mac/Linux: python3 app.py).
## Что видите сразу после запуска
При запуске исходной версии 0.1.0 окно/интерфейс игры не запускается: в терминале сразу выводится ошибка компиляции `SyntaxError: f-string: single '}' is not allowed` в строке 11 (`{secret}}`).
## Проверочные действия
| Версия | Исходное состояние | Последовательность действий | Наблюдаемый факт |
| --- | --- | --- | --- |
| 0.1.0 | Исходный файл app.py | Выполнить в терминале `python app.py` | Аварийное завершение до старта: `SyntaxError: f-string: single '}' is not allowed` на строке с выводом победы |
| 0.1.0 | Проверка кода вручную | Проверить строку 11 (`f"Победа! Ты угадал число {secret}}..."`) | Обнаружена лишняя закрывающая скобка `}` после переменной `secret` |
## Требование и расхождение
По требованиям: программа должна запускаться без ошибок, запрашивать число от 1 до 100, подсказывать «Больше!» или «Меньше!», считать попытки и при вводе `43` выводить поздравление с количеством попыток. Фактически в 0.1.0: запуск невозможен из-за синтаксической ошибки в f-строке.
## Цель и ограничения
Цель передачи 0.1.1: устранить синтаксическую ошибку в f-строке, подтвердить полный игровой цикл тестами и подготовить инструкцию по запуску для пользователя.
Ограничения: консольный интерфейс; секретное число жёстко задано в коде (`secret = 43`); отсутствует обработка нечислового ввода (ввод букв вызывает `ValueError`); прогресс не сохраняется после выхода.
